# Ironsight

[![Project Status: Inactive](https://www.repostatus.org/badges/latest/inactive.svg)](https://www.repostatus.org/#inactive)

A dual-webcam retro CRT-cabinet arcade shooter built with HTML5 Canvas, Vanilla JS, and MediaPipe Hands SDK.

> [!WARNING]
> **Project Status: Inactive**  
> This project is currently inactive and is not actively maintained. It remains here for archival and reference purposes.

## Features

- **Gesture Control**: Dual webcam gesture detection powered by MediaPipe Hands. Raise hands to aim, and pinch thumb and index finger to fire.
- **Keyboard Fallback**: Play with mouse/WASD or Arrow keys.
- **CRT Aesthetics**: Built-in scanlines, vignette, and retro arcade cabinet look and feel.
- **Vibrant Audio & Visuals**: In-game audio cues, bullet tracking, and particle effects.

## Controls

### Webcam Mode
- **Aim**: Raise hands to position the target.
- **Fire**: Pinch your thumb and index finger.

### Keyboard Mode
- **Player 1**: Move with mouse/WASD, fire with Space/Click.
- **Player 2**: Move with Arrow keys, fire with Enter.

## Running Locally

To run the development server locally:

```bash
npm install
npm run dev
```
